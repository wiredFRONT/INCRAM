# Work plan

Status: revised 2026-11-12 after research runs R1 and R2. The ledger wins where they differ.

## Method
Read every relevant source from its primary source, record each in the same template, then compare.
- Where sources overlap: align to ONE upstream and keep our own name as a stub pointing at it.
- Where they differ for a pivotal reason: that difference becomes a runtime route decision.
- Where nothing exists upstream: define it ourselves and label it as ours.

## Rules
1. Primary sources only. Blogs are leads, never evidence.
2. Pin the version and the date read.
3. Every statement is labeled UPSTREAM or MCPL.
4. One step per pass. Each pass ends with one decision for Jesse.
